# AI in Education: Student Outcomes and Well-being

**Power BI portfolio project · This is a work in progress**

## Project goal

The goal is to duild an dashboard for educators to explore **who uses generative AI, how students use it, and how academic outcomes and well-being compare due to AI**.

## What I did

- Built a report in **Power BI Service (browser)** using an existing student dataset.
- Created five summary cards covering student count, average AI hours, skill retention, and pre/post-semester GPA.
- Developed six charts exploring AI use by major and study year, study habits by prompt skill, use cases by institutional policy, GPA comparisons, and burnout risk by AI dependency.
- Improved the layout, chart titles, number sizes, and formatting to make the report easier to read.

## Skills demonstrated

- **Stakeholder-focused analysis:** turned educators’ questions into dashboard comparisons.
- **Metric selection:** used averages, counts, and percentage distributions for different questions.
- **Power BI visualization:** configured chart fields, aggregations, labels, and formatting.
- **Data storytelling:** organized the report around student profiles, AI practices, and outcomes.

## What I learned

- Average AI hours measure **usage intensity**, not the number of AI users.
- Chart type, category order, and axis scale can change how a pattern is perceived.
- Similar group averages are valid findings; small differences should not be exaggerated.
- Higher post-semester GPA does **not** prove that AI caused improvement.
- Clear labels and appropriate comparisons matter more than visual variety.
